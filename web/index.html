填的是放 screens.conf 的那个仓库（不是本程序仓库）。只读权限就能查看，编辑需要写权限。

当前是 file:// 打开的，浏览器会以 null 源发起请求，部分服务端会拒绝。 建议在本目录起个静态服务：python3 -m http.server 8080，然后访问 http://localhost:8080/index.html。
GitHub / Gitee / Gitea 填 owner/repo；GitLab 填 group/project（支持子组）
只存在这台机器的 localStorage 里，不会发到除上面这个 API 地址以外的任何地方。 GitHub 需要 Contents: Read and write；Gitee 勾 projects； GitLab 需要 api 或 write_repository。

原始文本
直接改文件内容。注释和空行会原样保留，保存前会做一次和 wall.sh 相同的校验。
新建主机
会创建 config/hosts/<主机名>.conf。主机名必须和那台机器上 hostname 的输出 完全一致，否则它不会用这个文件（会退回默认配置）。
第一块屏必须一起填：空的配置文件会让那台主机启动时报「无可用配置」， 而且这个空文件一旦提交就已经进仓库了。
